- [Error Handling](https://docs.mrscraper.com/docs/api/error-handling): Learn how the MrScraper API reports errors, including common error codes, response formats, and best practices for handling them in your app.
- [API Overview](https://docs.mrscraper.com/docs/api/overview): Comprehensive documentation for MrScraper's API endpoints, including authentication, pagination, error handling, and scraper management.
- [Pagination](https://docs.mrscraper.com/docs/api/pagination): Understand how pagination works in the MrScraper API, including parameters for controlling page size and navigating through large datasets.
- [Response Headers](https://docs.mrscraper.com/docs/api/response-headers): Learn how to monitor token usage, bandwidth usage, execution runtime, and target HTTP status codes returned in API response headers.
- [Get Screenshot](https://docs.mrscraper.com/docs/api/scraper-api/get-screenshot): Capture full-page or viewport screenshots of dynamic, JavaScript-rendered pages with the Get Screenshot endpoint, with real browser rendering enabled by default.
- [Listing Page](https://docs.mrscraper.com/docs/api/scraper-api/listing-page): Extract paginated item lists, catalog grids, and search results in one run with the Listing Page endpoint, handling numbered pages, scrolling, and Load More.
- [Scrape JSON](https://docs.mrscraper.com/docs/api/scraper-api/scrape-json): Extract structured, strongly-typed JSON from a single page with the Scrape JSON endpoint, using a natural language prompt instead of CSS selectors or XPath.
- [Scrape Markdown](https://docs.mrscraper.com/docs/api/scraper-api/scrape-markdown): Convert any web page into clean, LLM-friendly Markdown with the Scrape Markdown endpoint, stripping navigation, scripts, and ads for token-efficient AI input.
- [Scrape Sitemap](https://docs.mrscraper.com/docs/api/scraper-api/scrape-sitemap): Crawl target sites with the Scrape Sitemap endpoint to discover endpoints, map URL architecture, and generate seed URL lists before running bulk extraction jobs.
- [Get Proxy Requests Bandwidth](https://docs.mrscraper.com/docs/api/v3/analytic/proxy): Retrieve total proxy bandwidth usage aggregated per proxy username within a given date range using the MrScraper API.
- [Get Analytic Statuses](https://docs.mrscraper.com/docs/api/v3/analytic/status): Retrieve scrape status counts for a domain within a date range using the MrScraper API, with optional action and API token name filters.
- [Get All Results](https://docs.mrscraper.com/docs/api/v3/result/all): Retrieve all scraping results with data, status, token usage, and file paths using the MrScraper API, with sorting, filtering, and date ranges.
- [Get a Detailed Result](https://docs.mrscraper.com/docs/api/v3/result/detail): Retrieve detailed information for a single scraping result by its unique identifier with the MrScraper API, including data, status, and token usage.
- [Verify API Token](https://docs.mrscraper.com/docs/api/v3/authentication/verify-token): Verify your API token and retrieve subscription account information, including token usage, limits, and billing details, with the MrScraper API.
- [AI Scraper Response](https://docs.mrscraper.com/docs/api/v3/scraper/ai-response): Learn the response structure of the AI Scraper API, from the standard wrapper to the agent-specific data field, and how to interpret the results.
- [Web Unblocker](https://docs.mrscraper.com/docs/api/v3/scraper/unblocker-scraping): Retrieve the raw HTML of any webpage with the Web Unblocker endpoint, supporting browser rendering, geo-targeting, and waiting for DOM selectors.
- [Create and Run AI Scraper](https://docs.mrscraper.com/docs/api/v3/scraper/ai/ai-init): Create and run a new AI Scraper from natural language instructions using the MrScraper API, then save the scraperId to rerun it later.
- [Bulk Rerun AI Scraper](https://docs.mrscraper.com/docs/api/v3/scraper/ai/ai-rerun-bulk): Run an AI Scraper across multiple URLs at once with the MrScraper API, then poll the bulkResultId for merged data and per-URL status.
- [Rerun an AI Scraper](https://docs.mrscraper.com/docs/api/v3/scraper/ai/ai-rerun): Rerun an existing AI Scraper by scraperId and url with the MrScraper API, reusing cached results to cut token usage and execution time.
- [Cancel One Bulk Result by Result ID](https://docs.mrscraper.com/docs/api/v3/scraper/bulk/cancel-bulk-by-result-id): Cancel a running bulk scraping job using the bulk result ID returned from the bulk rerun response, with the MrScraper API.
- [Cancel All Bulk Results by Scraper ID](https://docs.mrscraper.com/docs/api/v3/scraper/bulk/cancel-bulk-by-scraper-id): Cancel the remaining pending URLs of a running bulk scraping job by scraper ID, using a single PATCH request to the MrScraper API endpoint.
- [Self-Heal a Manual Scraper](https://docs.mrscraper.com/docs/api/v3/scraper/manual/manual-heal): Ask AI to repair a Manual Scraper workflow with the MrScraper API when a target website changes its markup and the scraper returns empty data.
- [Bulk Rerun Manual Scraper](https://docs.mrscraper.com/docs/api/v3/scraper/manual/manual-rerun-bulk): Run a Manual Scraper across multiple URLs at once with the MrScraper API, then poll the bulkResultId for the asynchronous results.
- [Rerun a Manual Scraper](https://docs.mrscraper.com/docs/api/v3/scraper/manual/manual-rerun): Rerun an existing Manual Scraper by scraperId and url with the MrScraper API, reusing cached results to cut token usage and runtime.
